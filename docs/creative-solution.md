# Бүтээлч шийдэл: ISM Time Machine

## Санаа

Музейд зочин ихэвчлэн үзмэрийг нэг нэгээр нь хардаг. Харин тэнхимийн түүх гэдэг нь нэг үед болсон зүйлсийн уялдаа юм: тухайн жил юу болж, оюутнууд юу бүтээж, ямар технологи ашиглаж байв? Time Machine нь эдгээрийг нэг дэлгэцэд оноор нь нэгтгэнэ.

## Боломжууд

- **Он жилийн дуран:** багана бүр нэг он, өндөр нь тухайн оны агуулгын хэмжээг заана. Дарж эсвэл гулсуураар шилжинэ.
- **«Аялах» товч:** он жилүүдийг автоматаар дарааллаар нь үзүүлж, сүүлийн онд зогсоно.
- **Гурван хэсэгтэй танхим:** тэнхимийн түүх ба арга хэмжээ, тухайн оны бүтээл, технологийн хувьсал.
- **Технологийн хувьсал:** тухайн онд анх гарсан технологийг онцолж, тэр он хүртэлх хэрэглээг график хэлбэрээр үзүүлнэ.
- **Хуваалцах холбоос:** сонгосон он URL-д хадгалагдана (`/time-machine?year=2021`), түүхийн хуудаснаас шууд орж болно.
- **Хүртээмж:** гараар удирдах боломжтой гулсуур, хөдөлгөөн багасгах тохиргоог дэмжинэ.

## Ажиллах зарчим

1. `TimeMachinePage` нь `history_milestones`, `events`, нийтлэгдсэн `exhibits` хүснэгтүүдийг зэрэг татна.
2. `src/lib/timeline.js`-ийн `buildTimeline` цэвэр функц нь тэдгээрийг оноор нь бүлэглэж эрэмбэлнэ. Технологийн `Set`, `Map`-ийг он дараалан хуримтлуулж «анх гарсан» болон «нийт хэрэглээ»-г тооцно.
3. Сонгосон оныг React state биш URL query-д хадгалдаг тул хуудсыг сэргээсэн ч, холбоос хуваалцсан ч ижил он нээгдэнэ.

Бүх мэдээлэл өгөгдлийн сангаас ирдэг: шинэ бүтээл админаар нийтлэгдмэгц тухайн он болон технологийн график автоматаар шинэчлэгдэнэ. Гараар хадгалах жагсаалт байхгүй.

## Музейн зорилготой уялдах нь

- **Шинэ оюутанд:** тэнхим хаанаас эхэлж, хаашаа явж байгааг минутын дотор ойлгоно.
- **Төгсөгчид:** өөрийн сурч байсан оны бүтээл, арга хэмжээг олж дурсана.
- **Багшид:** хөтөлбөр ба оюутны ашигласан технологийн өөрчлөлтийг бодит өгөгдлөөр харна.
