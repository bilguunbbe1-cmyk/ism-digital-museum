# Wireframe ба хэрэглэгчийн урсгал

## Хэрэглэгчийн урсгал

```mermaid
flowchart TD
    A[Нүүр хуудас] --> B[Үзэсгэлэн: хайлт, шүүлт]
    B --> C[Үзмэрийн дэлгэрэнгүй]
    C --> D[Бүтээгчийн хуудас]
    A --> E[Time Machine]
    E --> C
    A --> F[Багш нар]
    A --> G[Арга хэмжээ] --> H[Зурагт цомог]
    A --> I[Бүртгүүлэх / Нэвтрэх]
    I --> J[Миний бүтээл]
    J --> K[Бүтээл нэмэх, засах: зураг оруулах]
    K -->|pending| L[Админы хяналт]
    L -->|published| B
```

## Гар утас

Цэс «Цэс» товч дотор нуугдана. Торон жагсаалтууд нэг багана болж, шүүлтүүр хоёр багана болно. Time Machine-ийн гурван хэсэг дараалан байрлана.

```
+------------------+
| ISM Museum  [Цэс]|
+------------------+
| 2024             |
| [<] [Аялах] [>]  |
| ||| | || |||     |
| Тэнхимийн түүх   |
| Тухайн оны бүтээл|
| Технологи        |
+------------------+
```
